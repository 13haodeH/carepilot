# Manual vs Agent 参与者执行包（v0.1）

这是一次尚未开始的作品集可用性测试执行包。`P01` 到 `P05` 只是匿名槽位；本文件不代表已经招募、同意、测试或产生结果。

## 开始前

1. 仅使用本项目的自构造模拟订单、政策、工单和图片 fixture；不得输入真实客户、地址、电话、支付资料或个人图片。
2. 向参与者说明：可随时停止，不影响任何评价；观察者只记录任务操作，不记录姓名、联系方式或屏幕中的个人信息。
3. 若课程、机构或招募渠道要求额外审批或说明，先按其规则完成；本执行包不替代这些要求。
4. 为参与者随机分配尚未占用的匿名槽位，在 `/experiment` 选择该槽位，按页面加载的 round 顺序完成 4 条任务。

## 对参与者的统一说明

“你将使用一个完全模拟的售后系统完成若干工单任务。请按页面中可见信息作答；不需要输入真实信息，也不存在真实退款、换货或外部操作。你可以在任意时刻停止。完成后请简要说明遇到的操作困难。”

## 观察者记录

每条任务以点击“开始 Round”时开始计时，以参与者保存最终状态或停止时结束。运行页自动写入 `manual-agent-study-v0.1.md` 已定义的匿名字段：任务 ID、条件、开始/结束时间、实际步骤数、是否达到目标状态、是否修改 Proposal、接管情况、单题 1–7 易用性评分和无个人信息的观察备注。4 条任务结束后，再填写一次 SUS-10；两个 CSV 都要导出。

高风险任务无论条件为何，都必须经过 `proposal_review`；观察者不得替参与者绕过审批，也不得把 Agent 建议直接视为可执行的退款、换货、退货、补偿或库存操作。

## 停止条件与输出边界

- 参与者表示不适、想退出，或模拟环境暴露意外个人信息时立即停止该任务。
- 未完成任务保留为未完成记录，不因方便计算而删除。
- 在 5 个匿名槽位全部完成前，不计算或宣传 Manual vs Agent 的效率、准确性、满意度或任何业务收益。
