# Manual vs Agent 对照实验协议（v0.2）

本协议用于替代 `manual-agent-study-v0.1.md` 的执行规则。任务与分配仍使用既有的自构造 fixture；v0.2 改变的是参与者作答规则和记录格式。不得将 v0.1 与 v0.2 的浏览器记录合并分析。

## 1. 实验要回答什么

在完全模拟的售后工作台中，比较参与者完成相同类型任务时的两种工作条件：

- `MANUAL`：参与者自行选择并使用模拟订单、物流、政策或材料工具，不提供 Agent 摘要。
- `AGENT_ASSISTED`：参与者可选择查看固定的 Agent 摘要、依据和建议，但仍须自己做最终决定。

本实验观察完成时间、最终状态是否符合冻结任务口径、实际使用的信息操作数、人工审核遵守情况、单题易用性与 SUS-10。它是模拟可用性实验，不是对真实客服效率或业务结果的证明。

## 2. 参与者规则（可直接朗读）

“你将完成四道完全模拟的售后任务。请只根据页面中的信息作答，不搜索外部资料，也不要询问观察者该选什么。普通任务中，工具按钮不是必选题：只点击你实际使用的信息或操作，然后选择你认为最合适的最终状态。系统不会告诉你对错。

如果题目标为 HIGH RISK，你必须先打开‘人工审核 Proposal’，再选择‘提交人工审核’；这里不会发生真实退款、换货、退货、补偿或库存变更。若你不想继续，可以选择‘停止并记录接管’，该记录会被保留。每题结束后按真实感受评分；四题都结束后再完成一次 SUS-10。”

观察者只负责启动页面、计时故障处理和下载文件，不解释政策、不提示答案、不建议点击哪些工具。

## 3. 参与者如何作答

1. 选择分配给自己的匿名槽位 `P01`–`P05`，阅读题干和开始前规则并确认。
2. 点击“开始 Round”。计时从此刻开始。
3. 按需要点击模拟工具。每次点击会显示该工具的模拟信息，并计为一次信息操作；普通任务不需要点完可见工具。
4. 在三个最终状态中选择一个：
   - `已解决`：当前证据足以完成低风险模拟跟进或政策说明。
   - `请求补充材料`：关键事实或材料缺失。
   - `提交人工审核`：涉及高风险权益或证据冲突。
5. HIGH RISK 任务必须打开人工审核 Proposal 且选择 `提交人工审核`；这是安全门槛，不是参与者需要猜测的答案。
6. 给本题打 1–7 分易用性评分，1 为非常困难、7 为非常容易；可留下不含个人信息的备注。
7. 保存回答。页面不反馈正确性，直接进入下一轮。完成四题后独立回答 SUS-10 的十道 1–5 分题目。

## 4. 输入与分配

- 使用 `fixtures/manual-agent-tasks-v0.1.json` 的 10 个场景对、20 条条件任务和自构造模拟信息。
- 使用 `fixtures/manual-agent-assignment-v0.1.json` 的 5 个匿名槽位与 20 条预分配；每个槽位 4 条任务，`MANUAL` 与 `AGENT_ASSISTED` 各 2 条。
- 同一参与者不得完成同一场景对的两个条件；四个 Round 已做 3:2、2:3、3:2、2:3 的条件交叉平衡。

## 5. 自动记录与导出

浏览器只写入 v0.2 本地存储；不读取或合并旧 v0.1 记录。结束后下载并一并交给研究者：

- `carepilot-manual-agent-records-v0.2.csv`：一任务一行，包含匿名槽位、任务条件、开始/结束时间、`information_actions`、`information_action_count`、最终状态、冻结口径正确性、高风险门槛、Proposal 修改、停止/接管、1–7 易用性与脱敏备注。
- `carepilot-manual-agent-sus-v0.2.csv`：一参与者一行，包含 SUS-10 的原始十题答案。第 2、4、6、8、10 题需在分析时按标准规则反向计分；不要将单题 1–7 易用性当作 SUS。

`information_action_count` 只统计参与者主动使用的模拟信息或工具，不含最终状态选择，也不等于 fixture 中的预设步骤数。这样它才能反映实际工作路径。

## 6. 停止与边界

- 不收集真实客户、订单、地址、电话、支付信息、个人图片或录屏。
- 参与者可随时停止；`STOPPED` 记录保留，不重做、不删除。
- 招募前按适用的课程、机构或招募渠道要求完成必要说明或审批。
- 在 5 个匿名槽位完成前，不计算或宣传效率、正确性、满意度、GMV、留存或其他业务结论。
