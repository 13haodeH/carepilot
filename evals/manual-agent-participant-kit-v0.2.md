# Manual vs Agent 参与者执行包（v0.2）

这是一次尚未开始的模拟可用性测试。`P01` 到 `P05` 是匿名任务槽位，不代表已招募、已同意或已经产生结果。

## 给参与者的说明

你将完成 4 道完全模拟的售后任务。没有真实订单、客户、支付、图片或外部操作。请只根据页面展示的信息作答；不要搜索外部资料，也不要询问观察者哪一个答案正确。

每题中，你可以按需要点击模拟工具。工具不是必选清单：只点击你实际使用的信息或操作。之后选择一个你认为最合适的最终状态，并按本题真实感受打 1–7 分。系统不会告诉你答案是否正确。

若题目显示 HIGH RISK，请先点击“人工审核 Proposal”，再选择“提交人工审核”。这条规则保护高风险处置：本实验不会执行退款、换货、退货、补偿或库存变更。

你可以随时停止；点击“停止并记录接管”即可。完成四题后，请独立填写一次 SUS-10 问卷。

## 观察者操作清单

1. 指派尚未使用的 `P01`–`P05` 槽位；不要在页面或备注中填写姓名、联系方式或其他个人信息。
2. 打开 `/experiment`，选择槽位，请参与者自行阅读开始前规则并勾选确认。
3. 观察者不得解释题干、政策、工具或正确答案。只在页面/设备故障时提供技术协助。
4. 参与者完成或停止后，不要删除或重开同一任务；四题结束后让其独立填写 SUS-10。
5. 下载 `carepilot-manual-agent-records-v0.2.csv` 与 `carepilot-manual-agent-sus-v0.2.csv`，确认两个文件都已保存后，才可以清空当前浏览器 v0.2 记录。

详细规则、字段与边界见 [manual-agent-study-v0.2.md](./manual-agent-study-v0.2.md)。
