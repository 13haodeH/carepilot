# Manual vs Agent v0.2 匿名模拟实验结果

- 数据状态：已收到并核验的 v0.2 本地导出记录
- 数据范围：20 条任务记录、5 个匿名槽位、5 份 SUS-10
- 数据来源：项目负责人提供的 `carepilot-manual-agent-records-v0.2.csv` 与 `carepilot-manual-agent-sus-v0.2.csv`
- 结论性质：**小样本、模拟环境下的描述性观察**，不代表真实客服、真实订单或业务效果

## 1. 数据完整性与安全核验

| 检查项 | 结果 |
| --- | --- |
| 任务覆盖 | 20 / 20 条预分配任务各出现一次；P01–P05 各 4 条 |
| 条件平衡 | Manual 10 条，Agent-assisted 10 条 |
| 状态 | 20 / 20 为 `COMPLETED`；无 `STOPPED` |
| 正确性 | 两个条件均为 10 / 10 达到冻结 `target_outcome` |
| 高风险安全门槛 | 6 / 6 高风险任务选择人工审核且记录到人工门槛 |
| Agent Proposal 修改 | 3 条高风险 Agent-assisted 任务中 1 条记录为已修改 Proposal |
| SUS-10 | 5 / 5 槽位各一份；无缺题 |

本次核验未发现 schema 版本、任务分配、重复记录、信息操作计数或高风险门槛不一致的问题。原始 CSV 未被修改。

## 2. 条件级描述性结果

| 指标 | Manual（n=10） | Agent-assisted（n=10） | Agent - Manual |
| --- | ---: | ---: | ---: |
| 平均完成时间 | 21.7 秒 | 18.3 秒 | -3.4 秒（-15.7%） |
| 中位完成时间 | 18 秒 | 16 秒 | -5 秒（按 10 个场景对的中位差） |
| 平均信息操作数 | 5.2 | 2.3 | -2.9 |
| 中位信息操作数 | 5.0 | 2.0 | — |
| 冻结口径正确率 | 100.0%（10 / 10） | 100.0%（10 / 10） | 0.0 个百分点 |
| 平均单题易用性（1–7） | 5.9 | 5.6 | -0.3 |
| 中位单题易用性（1–7） | 6.0 | 6.0 | 0.0 |

按十个场景对比较，Agent-assisted 在 6 对中用时更短、4 对中更长；平均差为 -3.4 秒，中位差为 -5 秒。该差异只描述这组冻结模拟任务中的记录，不做显著性、因果或生产效率推断。

## 3. SUS-10

SUS 是参与者完成四题后的系统级感受，不能拆分为 Manual 或 Agent-assisted 的独立满意度结论，也不能替代每题的 1–7 易用性评分。

## 4. 可支持的结论

在这 20 条自构造模拟任务中，Agent-assisted 条件对应的平均记录用时和信息操作数都更低，同时没有出现高风险绕过人工审核的记录。两种条件都达到冻结任务的目标状态，因此这批任务没有观察到正确性差异。单题易用性没有显示出 Agent-assisted 的优势，系统级 SUS 分数在 5 个匿名槽位中存在较大差异。

## 5. 不能支持的结论与下一步

- 不能据此声称真实客服效率、准确率、GMV、满意度、留存或成本得到提升。
- 只有 5 个匿名槽位；同一场景对的两个条件由不同槽位完成，因此场景对差异仍可能混入参与者差异。
- Agent-assisted 条件可见的模拟工具入口本来就少于 Manual 条件，信息操作数下降部分来自界面设计，不能直接解释为认知负荷或生产力下降。
- 两种条件正确率均为 100%，存在天花板效应。若要验证准确性差异，需要在保留高风险人工审核规则的前提下，增加证据冲突、政策边界和工具异常任务，并扩大匿名参与者数量。

下一阶段应先基于这份描述性结果做坏例访谈或增加更具区分度的模拟任务；任何新任务都应新建版本，不修改已完成的 v0.2 原始记录。
