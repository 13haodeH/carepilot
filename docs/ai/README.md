# CarePilot AI 文档入口

此目录记录模型相关的**版本、坏例、修复归因与后续规则**。它不将“改了 Prompt”当作默认解法：问题可能来自 Tool 轮次、检索、输入证据、确定性权限门禁或任务设计。

| 文档 | 用途 |
| --- | --- |
| [Prompt 版本台账](./PROMPT-REGISTER.md) | 已执行的 Prompt/配置版本、可追溯缺口与未来版本的准入规则 |
| [坏例与修复台账](./BADCASE-REGISTER.md) | 已知失败、修复层、验证版本和未解决项 |
| [真实 Agent 运行说明](../REAL_AGENT_SETUP.md) | 环境、启动与运行前检查；不包含任何密钥 |
| [Stage 18–20](../worklog/2026-09-11-stage-18-real-evaluation-v02.md) | 真实模型评测、失败、最小修复与复跑结果 |

## 更新规则

任何 Prompt、模型、Tool allowlist、策略、schema、评测样本或评分口径改变前，必须先登记：

1. 变更问题与假设；
2. 新版本 ID、完整内容哈希、代码路径与配置；
3. 固定的模型、政策、样本和评测口径；
4. 预期收益与失败边界；
5. 真实/离线运行 ID、前后结果、坏例与发布决定。

没有以上记录的文本变动不能被包装为“Prompt V1 → V2 效果提升”。
