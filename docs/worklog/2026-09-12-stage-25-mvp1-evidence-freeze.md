## 2. 决定

1. MVP1 的客服价值主线固定为：减少信息拼接、提高决策前信息完整度、让低风险流程受控推进、让高风险权益决定保留人工掌控。
2. 真人任务中信息完整度与人工审核机制作为作品集主证据；时间、正确率和信息操作的跨批次不稳定性作为限制披露，不用于“提效提升”结论。
3. 真实 Agent / Vision / Tool / Policy 运行作为可靠性附录，证明技术链路真实执行，但不替代客服业务效果。
4. 不再扩展实验台、Multi-Agent、Redis、Reranker、语音或新的后台能力。所有后续实质性变化进入 `docs/mvp-v2/`。

## 4. MVP1 证据边界

- MVP1 是个人作品集与技术 Demo，不是生产上线。
- 没有真实客户、订单、支付、库存或履约系统写入；公开页不暴露服务端密钥。
- 不能主张客服处理时间缩短、自动处置覆盖率提升、SLA/GMV/满意度/成本改善。
- 高风险退款、换货、退货、补偿和库存改变始终需要人工最终确认。
