# 阶段十二工作记录：Manual vs Agent v0.2 数据核验与描述性结果

- 记录日期：2026-09-09
- 对应计划：5 人 Manual vs Agent 模拟可用性实验的数据核验与结果复盘
- 交付阶段：**用户提供的匿名 v0.2 CSV 已核验并形成描述性结果记录**

## 1. 输入与核验

项目负责人提供 `carepilot-manual-agent-records-v0.2.csv` 与 `carepilot-manual-agent-sus-v0.2.csv`。核验使用 v0.2 schema、20 条冻结分配和 v0.2 高风险人工审核规则；原始 CSV 未被修改或写回。

结果：20 条任务分别覆盖 P01–P05 的 4 条预分配任务；Manual / Agent-assisted 各 10 条；5 份 SUS-10 均完整。没有重复任务、任务分配不一致、信息操作计数不一致或高风险人审越过的问题。

## 2. 描述性观察

- Manual 平均完成时间为 21.7 秒，Agent-assisted 为 18.3 秒；十个场景对的平均差为 -3.4 秒、中位差为 -5 秒。
- Manual 平均信息操作数为 5.2，Agent-assisted 为 2.3；两个条件的冻结目标状态正确率均为 10 / 10。
- Manual / Agent-assisted 的平均单题易用性分别为 5.9 / 5.6（1–7）；5 个匿名槽位的 SUS-10 平均为 76.5，中位数为 75.0。
- 6 / 6 高风险任务保留人工审核门槛；3 条高风险 Agent-assisted 任务中 1 条记录了 Proposal 修改。

这些数字只描述这批自构造模拟任务及匿名槽位记录，不能解释为真实客服或业务改善。

## 3. 已识别限制

- 样本只有 5 个匿名槽位；同一场景对由不同槽位完成两个条件，参与者差异仍是混杂因素。
- Agent-assisted 可见工具入口比 Manual 少，信息操作数并非纯粹的认知负荷或生产力指标。
- 两个条件正确率均为 100%，说明当前任务在正确性维度的区分度不足。
